# AniDale Server

Для того, чтобы запустить сервер, требуется произвести следующие действия:

- склонировать репозиторий и перейти в папку сервера

```
git clone https://github.com/fidGaib/anidale
cd anidale/server
```
- установить зависимости

```
npm i
```
- создать .env файл; это можно сделать как вручную, так и создать шаблонный файл при помощи скрипта `generate-env.ts`

```
npx vite-node generate-env.ts
```

- по желанию установите Redis и укажите `REDIS_URL` в `.env`: он включает кэш каталога и музыки, общие онлайн-статусы и ограничители частоты. Без Redis сервер работает без кэша, лимиты считаются в PostgreSQL;

- сгенерировать типы для GraphQL при помощи `codegen.ts`

```
npm run codegen
```
- произвести создание базы данных при помощи Prisma (миграции из `prisma/migrations`)

```
npm run db:migrate
```
- запустить сервер; в случае, если требуется перезагружать сервер при изменении файлов(во время разработки), следует использовать `npm run dev`, в противном случае можно использовать `npm run start:prod`

```
npm run dev        # при разработке, перезагружается в случае изменения файлов
npm run build      # собирает dist для продакшена
npm run start:prod # запускает собранный dist без компиляции на лету
```

Проверка живости: `curl http://127.0.0.1:5000/healthz`.
Резервная копия базы и `storage`: `npm run backup` (см. `DEPLOY.md`).

## Каталог аниме и администратор

Управлять каталогом (релизы, серии, расписание, жанры) может пользователь с ролью `admin`.
Роль выдаётся скриптом по почте или логину:

```
npm run admin -- Admin[F.I.D.]
npm run admin -- user@example.com
```

После входа под администратором в меню появляется пункт «Админка», страница — `/admin/anime`.
Администратор загружает постеры, кадры и видео серий, создаёт релизы и планирует выход серий;
после загрузки серии её запись из расписания удаляется автоматически. Черновики релизов
не показываются гостям. Файлы лежат в `storage/anime/` (постеры, кадры, видео) и открыты
без входа, потому что каталог публичный.

Демонстрационные данные (релизы, жанры, серии, расписание) можно создать командой:

```
npm run seed:anime
```

Скрипт заменяет содержимое каталога аниме и копирует картинки из `client/public/anime`.
Видео для демо-серий берётся из первого mp4 в `storage/videos`; если его нет, серии
создаются без видео.

#AniDale Client

Для того, чтобы запустить клиент, требуется произвести следующие действия:

- Перейти в папку клиента

```
cd anidale/client
```
- установить зависимости

```
npm i
```

- сгенерировать типы для GraphQL при помощи `codegen.ts`

```
npm run codegen
```
- запустить сервер; в случае, если требуется перезагружать сервер при изменении файлов(во время разработки), следует использовать `npm run dev`, в противном случае можно использовать `npm start`

```
npm run dev # при разработке, перезагружается в случае изменения файлов
npm start   # просто запускает сервер, не перезагружает его при изменении файлов
```
